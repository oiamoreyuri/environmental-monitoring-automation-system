# Environmental Monitoring Automation System

Operational environmental monitoring and traceability automation system designed to improve data integrity, operational reliability and workflow efficiency in regulated environments.

---

## Overview

This project was developed to replace manual paper-based environmental monitoring routines with a digital and automated workflow focused on traceability, compliance and operational reliability.

The system was designed for low operational friction in industrial environments while maintaining strong data integrity and audit readiness.

---

## Problem

Manual environmental monitoring workflows created several operational and compliance risks:

- paper-based records vulnerable to loss and transcription errors
- delayed identification of critical deviations
- inconsistent data standardization
- excessive manual data entry
- low traceability during audits
- operational inefficiency caused by duplicated work

---

## Solution

The project introduced a low-cost automation architecture combining QR code identification, digital forms, cloud-based storage and automated data processing workflows.

Operators scan a QR code attached to monitoring devices and are redirected to a pre-configured digital form containing contextual operational metadata.

Submitted data is automatically centralized, validated and processed for trend analysis and audit-ready reporting.

---

## System Workflow

1. QR code attached to monitoring equipment
2. Operator scans the code using a mobile device
3. Dynamic form opens with pre-filled metadata
4. Operator inputs temperature and humidity values
5. Data is automatically stored in cloud infrastructure
6. Automated ETL routines process and validate records
7. Processed data is consolidated for operational analysis and audit reporting
