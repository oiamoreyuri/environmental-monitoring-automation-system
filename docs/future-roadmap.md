# Future Roadmap

## Real-time Alert System

Planned implementation of automated alert pipelines for abnormal environmental monitoring conditions.

Future capabilities:

- instant anomaly notifications
- threshold-based alerts
- supervisor escalation workflows
- operational incident visibility

Potential technologies:

- Python background services
- Go-based monitoring workers
- WhatsApp or Telegram integrations

---

## Database Migration

The current architecture uses Google Sheets as a lightweight operational database.

Future migration goals:

- improved scalability
- stronger relational consistency
- better performance
- advanced querying capabilities

Potential future technologies:

- PostgreSQL
- REST API integration
- centralized backend services

---

## Interactive Dashboards

Future plans include development of operational dashboards for real-time monitoring visibility.

Potential features:

- live environmental monitoring panels
- historical trend visualization
- anomaly heatmaps
- audit-oriented reporting views

Possible technologies:

- Looker Studio
- Power BI
- Grafana

---

## Monitoring Reliability Improvements

Future reliability improvements may include:

- offline submission fallback
- retry mechanisms for failed submissions
- automated validation layers
- operational redundancy improvements

---

## Infrastructure Evolution

Long-term architectural evolution may include:

- dedicated backend services
- containerized workloads
- API-based integrations
- event-driven processing pipelines

The goal is evolving from lightweight operational automation toward a more scalable and maintainable monitoring ecosystem.

---

## Engineering Philosophy

The project evolution strategy prioritizes:

- operational reliability
- maintainability
- low operational friction
- scalable architecture
- pragmatic implementation decisions

The objective is gradual evolution without disrupting operational workflows already adopted by quality teams.
